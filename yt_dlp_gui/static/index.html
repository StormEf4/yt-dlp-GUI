YouTubevert by StormEf4

YouTube to audio & video, in one click

A yt-dlp fork. All credit to them, this is simply my GUI.

FFmpeg is missing. It's needed to convert downloads into audio files. Install it from ffmpeg.org (or your package manager), then restart this app.
YouTube downloads may fail. yt-dlp needs to download from YouTube. Run (or see the yt-dlp guide), then restart this app.

Tip: paste several YouTube links at once, or drag a link from your browser onto this window.
